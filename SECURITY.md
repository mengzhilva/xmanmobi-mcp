# Security Policy

Please do not disclose security vulnerabilities, credentials, tokens, customer identifiers, or advertising data in public GitHub issues.

Report security concerns privately through the contact method listed on the [Xmanmobi support page](https://ai.xmanmobi.com/mcp-support.html). Include a concise description, affected endpoint or component, reproduction steps, and potential impact. Remove all real customer data and secrets from the report.

The public plugin is read-only, but authorization and customer-scope issues should still be treated as security-sensitive.
