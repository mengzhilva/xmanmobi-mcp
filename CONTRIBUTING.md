# Contributing

Documentation corrections, prompt examples, translations, and compatibility reports are welcome.

Before opening a pull request:

1. Do not include credentials, access tokens, customer data, screenshots containing private data, or internal endpoint details.
2. Keep examples read-only and consistent with the published tool capabilities.
3. Use clear reproduction steps for compatibility issues.
4. Do not use public issues for security reports; follow `SECURITY.md`.

The hosted MCP service and Xmanmobi backend are maintained privately. Contributions to this repository do not grant access to those systems.
