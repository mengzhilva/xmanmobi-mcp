# Prompt examples

Replace the customer name and date range as needed. When more than one customer is available, always identify the target customer explicitly.

## Overview

```text
Use Xmanmobi to summarize Google and Facebook advertising performance for Customer A from 2026-10-01 to 2026-10-31. Include spend, impressions, clicks, conversions, conversion value, CTR, CPC, CPA, and ROAS.
```

## Period comparison

```text
Compare Customer A's advertising performance for the last 7 days with the previous 7 days. Explain the largest changes using only the returned data.
```

## Campaign diagnosis

```text
Diagnose Customer A's Google campaigns for the last 30 days. Rank the campaigns needing attention and cite the metrics behind each finding. Do not change the campaigns.
```

## Creative analysis

```text
Analyze Customer A's Meta ad creatives for the last 30 days. Identify strong and weak creatives, missing metadata, and possible next tests.
```

## Search-term analysis

```text
Analyze Customer A's Google search terms for the last 30 days. Separate converting terms, high-spend non-converting terms, and possible negative keywords. Do not edit the account.
```

## Conversion funnel

```text
Review Customer A's conversion funnel for both Google and Facebook this month. Show where the largest measurable drop-offs occur and note any missing data.
```

## Data quality

```text
Check Customer A's advertising data quality. Identify unbound accounts, stale synchronization, missing conversion values, and fields that cannot be distinguished from true zero values.
```
